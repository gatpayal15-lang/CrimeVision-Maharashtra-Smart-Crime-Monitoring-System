# CrimeVision-Maharashtra-Smart-Crime-Monitoring-System
A Python-based crime analytics dashboard for Maharashtra featuring interactive visualizations, district-wise crime analysis, and safety mapping using Pandas, Matplotlib, Tkinter, and Folium.
## 📌 Project Overview

The **Maharashtra Crime Report** is a Python-based data analysis and visualization project developed as a PSDL Mini Project.

The project analyzes crime-related data to identify crime patterns, affected districts, peak crime hours, crime types, case status, and overall crime trends.

## 🎯 Objectives

- Analyze crime data using Python.
- Identify the most common types of crimes.
- Find districts with the highest number of reported crimes.
- Analyze crime patterns based on time.
- Study case closure and pending case information.
- Visualize important findings using graphs and charts.
- Generate meaningful insights from the dataset.

## 🛠️ Technologies Used

- **Python**
- **Pandas**
- **Matplotlib**
- **Tkinter**

## 📚 Python Libraries

### Pandas
Pandas is used for:
- Reading and processing datasets
- Data cleaning
- Grouping and aggregation
- Counting crime types
- District-wise analysis
- Year-wise analysis

### Matplotlib
Matplotlib is used to visualize the analyzed data through graphs and charts.

### Tkinter
Tkinter is used to provide a graphical user interface for displaying crime analysis results.

## 📊 Analysis Performed

The project provides analysis such as:

- Most common crime type
- Most affected districts
- Peak crime hours
- Crime trends over the years
- Case closure rate
- Top crime districts
- Crime type distribution
- Case status analysis

## 📈 Visualizations

The project uses different visualizations to represent crime patterns, including:

- Bar charts
- Pie charts
- Ranked horizontal bar charts

The peak crime hours are analyzed and displayed using a ranked visualization. 

## 🔍 Key Features

- Crime data analysis using Pandas
- District-wise crime analysis
- Crime-type analysis
- Time-based crime analysis
- Case closure analysis
- Graphical visualization using Matplotlib
- Interactive analysis through a Tkinter interface
